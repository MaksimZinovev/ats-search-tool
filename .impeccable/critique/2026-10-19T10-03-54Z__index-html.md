## Anti-Patterns Verdict

Detector: 1 finding — flat-type-hierarchy: sizes 10/11/12/13/15px, adjacent ratio ~1.08 (needs ≥1.25). Agrees with LLM read.

## Priority Issues

1. **[P1] Header wall**: 259px prose; Search button at y=469. First-timer reads 7 lines before one control. Fix: masthead (h1 + one lead line + dynamic platform count); how-it-works moves into the Search panel as a context hint; trust line merges with footer.
2. **[P1] Flat type scale**: consolidate 10/11/12/13/15 to 3 sizes {11, 14, 32} so nearest step ratio = 1.27.
3. **[P2] No cancellable search**: ~29 platforms × 1s pacing locks the UI; add Stop control.
4. **[P2] Search not shareable/persistent**: keywords/location/sort not in URL; no reload restore.
5. **[P3] Hardcoded "29 ATS platforms"** lies once user adds a custom platform; render count dynamically.
